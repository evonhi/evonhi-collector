# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository. Include what you found, how to reproduce it and
the impact you expect. You will get an acknowledgement within 5 working days.

## Scope

The in-cluster agent and its Helm chart: anything that lets it read or send more than documented, or that weakens the cluster it runs in.

## Supported versions

Only the latest release receives security fixes while the project is pre-1.0.
